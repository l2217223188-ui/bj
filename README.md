# 定制衣柜报价系统 · 多门店版

三层账号 + 门店数据隔离，部署在 Netlify（Functions + Blobs）。

## 账号层级

| 层级 | 账号 | 能做什么 |
|---|---|---|
| 总账号 | 你（admin） | 建门店、停用门店、进入任意门店查看/操作 |
| 主账号 | 每个门店一个（财务/老板） | 本店价格表、报价单、设计师账号；负责定价 |
| 设计师 | 主账号创建 | 只填尺寸，看不到任何价格，保存后进入「待报价」 |

## 使用流程

1. 总账号登录 → 门店管理 → 新建门店（填门店名 + 主账号用户名密码）
2. 把「用户名 + 初始密码」发给店里财务
3. 财务登录 → 商品库设置 → 账号安全 → 新增设计师账号
4. 设计师登录 → 填客户和尺寸 → 保存（状态：待报价）
5. 财务打开这张单 → 定价 → 保存（状态：已报价）

## 部署

1. 把本目录推到 GitHub 仓库
2. Netlify → Add new site → Import an existing project → 选仓库
3. 构建设置**全部留空**（netlify.toml 已配好）
4. 首次登录 `admin` / `admin888` → 立刻改密码

## 文件

- `public/index.html` 前端单文件（界面 + 样式 + 脚本 + 登录层）
- `functions/api.mjs` 后端（登录、三层权限、门店隔离、报价、日志）
- `netlify.toml` / `package.json`

## 说明

- 数据在 Netlify Blobs，不在仓库里
- 备份：登录后「商品库设置 → 数据备份 → 导出备份文件」
- 没有「一键下载 PDF」，用浏览器「打印 → 另存为 PDF」
- 从旧版（单账套）升级：首次加载会自动迁移，原管理员变成总账号，
  原有数据归到「默认门店」

## 新功能

### 比价（升级材料报价）

开单页每个柜体右侧有 **「比价」** 按钮：按这个柜体的尺寸，把价格表里所有品牌 / 材质组合算一遍，
列出单价、柜体合计、比当前贵多少 / 便宜多少，点「套用」直接换成那个组合。

适合客户说「升级成 X 材料要多少钱」时，一秒报出来。

### 设计师可直接出价

「商品库设置 → 选项管理 → 设计师出价」有个开关：

- **关闭（默认）**：设计师保存后是「待报价」，等主账号定价
- **开启**：设计师保存即按价格表自动出价，状态直接是「已报价」，可以当场给客户看报价单

开启后设计师能看到价格，但仍然改不了价格表、看不到别家门店的数据。
### 数据体检（防人为录错）

「商品库设置」最上方有 **数据体检** 卡片，自动扫描以下问题：

| 级别 | 检查项 |
|---|---|
| 严重 | 价格组合重复（同品牌+同柜体材质+同门板材质出现多行，价格不同） |
| 严重 | 单价漏填或为 0 |
| 严重 | 成本 ≥ 售价（每㎡倒亏） |
| 严重 | 同名增项单价不同 |
| 严重 | 同名五金方案加价不同 |
| 提醒 | 毛利率低于 15% |
| 提醒 | 投影价与延米价不一致（超过 5%） |
| 提醒 | 价格表用了「选项管理」里没有的柜体/门板材质（下拉选不到，永远匹配不上） |
| 提醒 | 增项单价为 0 / 名称为空 |
| 提醒 | 选项重复或空行（空间、柜子名称、材质、柜体类型） |
| 提醒 | 历史单据里同材料组合单价不一致（可能手改过） |

### 保存前检查

点「保存报价」时自动检查这张单：

- 柜体尺寸没填完（金额会算成 0）
- 柜体没填深度
- 同一单里相同材料组合的柜体单价不一致
- 同空间同名柜体重复录入

发现问题会弹清单，可以「返回修改」或「确认无误，继续保存」。
